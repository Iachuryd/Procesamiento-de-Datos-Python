# Procesamiento-de-Datos-Python

## Descripción

Este repositorio contiene una colección de cuadernos en Python desarrollados como actividad introductoria de la materia **Procesamiento de Datos**.  
El objetivo de estos ejercicios es fortalecer los conceptos básicos del manejo, procesamiento y análisis de datos utilizando como lenguaje de programación Python, así como familiarizarse con el uso de cuadernos Jupyter y el control de versiones mediante repositorios.

## Estructura del repositorio

El repositorio se organizo de la siguiente manera:

procesamiento-datos/

```
│── README.md
│── notebooks/
│   │── 01-Python-Cadenas.ipynb
│   │── 02-Python-Tuplas.ipynb

│   │── 05-Python-Diccionarios.ipynb

│   │── 08-Python-Funciones.ipynb
│   │── 09-Python-Clases.ipynb
│   │── Practica_Bono_1
```

## Descripción de los cuadernos

Cada cuaderno incluye:
- Membrete con identificación del estudiante
- Desarrollo completo de los ejercicios propuestos
- Código funcional y documentado
- Comentarios explicativos sobre los conceptos aplicados
- Conclusiones al final del cuaderno

## Contenido trabajado 

- **Cadenas:** Manipulación y métodos de texto en python.
- **Tuplas:** Estructras inmutables y acceso a elementos.
- **Listas:** Creación, modificación y recorrido de elementos.
- **Conjuntos:** Operaciones como unión, comparación y subconjuntos.
- **Diccionarios:** Manejo de estructuras clave-valor.
- **Condicionales**: Uso de if, elif, else, operadores lógicos y de comparación.
- **Bucles:** Iteración con for, while y uso de range.
- **Funciones:** Definición, parámetros, retorno de valores y alcance de variables.
- **Clases:** Introducción a la programación orientada a objetos, atributos y métodos.
- **Práctica Bono:** Ejercicio integrador aplicando los conceptos vistos durante el curso.



## Ejecución de los cuadernos

1. Tener instalado Python.
2. Contar con Jupyter Notebook o Jupyter Lab.
3. Clonar el repositorio:
   ```
   https://github.com/Iachuryd/Procesamiento-de-Datos-Python
   ```
4. Acceder a la carpeta del proyecto y abrir el notebook deseado y ejecutar las celdas de manera secuencial.
