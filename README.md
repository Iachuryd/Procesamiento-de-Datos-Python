# Procesamiento-de-Datos-Python
Este repositorio contiene una colección de cuadernos en Python desarrollados como actividad de Procesamiento de Datos. El objetivo de estos ejercicios es afianzar conceptos básicos del manejo, procesamiento y análisis de datos utilizando Python, así como familiarizarse con el uso de cuadernos Jupyter y el control de versiones mediante repositorios.
